# 🍱 今天吃什麼？轉盤 — 規格書

## 一、發想動機
每天中午、晚上最難的問題就是「要吃什麼」。和朋友討論常常變成「都可以」「隨便」，最後浪費很多時間。
所以我想做一個**轉盤網頁**：把候選的食物或餐廳放進去，按一下就由轉盤幫忙決定，而且會記得最近吃過什麼，避免連續好幾天都吃一樣的東西。

## 二、目標使用者
- 有選擇困難的學生、上班族
- 一群朋友要決定聚餐吃什麼

## 三、功能規格

| # | 功能 | 說明 |
|---|------|------|
| 1 | 轉盤顯示 | 用 Canvas 依照候選項目數量平均分割成彩色扇形，每格顯示名稱，上方有指針 |
| 2 | 轉動抽選 | 按「開始轉！」後轉盤旋轉 4～5 秒，由快到慢（easeOutQuart 緩動）停下；指針停在哪一格，結果就是那一格 |
| 3 | 結果彈窗 | 停下後跳出視窗顯示結果，可以選「就決定是你了！」（記錄下來）或「不要，再轉一次」 |
| 4 | 新增項目 | 輸入框輸入名稱，按 Enter 或「新增」加入清單；不可空白、不可重複、最多 20 個、每個最多 12 字 |
| 5 | 刪除項目 | 每個項目旁有 ✕ 可刪除；至少要 2 個項目才能轉 |
| 6 | 範本清單 | 一鍵套用「午餐／晚餐／飲料／宵夜」預設清單，也可以一鍵清空 |
| 7 | 排除最近吃過 | 可勾選是否排除最近 1／2／3／5 筆吃過的項目；被排除的項目在轉盤上變灰色、清單上加刪除線並標示「最近吃過」。若全部都被排除，則自動改為不排除並提示 |
| 8 | 吃過紀錄 | 確認結果後記錄名稱與時間（最多保留 20 筆），可以清除 |
| 9 | 資料保存 | 候選清單與紀錄存在瀏覽器 localStorage，重新整理不會消失 |
| 10 | 音效 | 轉動時每經過一格發出「滴」聲（Web Audio API 產生，不需外部音檔），可關閉 |
| 11 | 響應式設計 | 電腦版左右兩欄，手機版上下排列；支援深色模式 |

## 五、技術
- 單一 `index.html`，HTML + CSS + JavaScript 全部寫在同一個檔案，不使用任何外部套件
- Canvas 2D 繪製轉盤、`requestAnimationFrame` 做動畫
- `localStorage` 儲存資料
- 部署：GitHub Pages

## 六、抽選邏輯（確保指針與結果一致）
1. 先從「沒有被排除」的項目中隨機選出目標 `target`
2. 計算讓 `target` 那一格中心轉到正上方所需的角度，再加上 5～7 圈與一點隨機偏移（讓它不會每次都停在正中間）
3. 用緩動函數播放動畫，最後角度剛好落在目標格內

## 七、與 AI 反覆調整的過程
1. 一開始只有「轉盤＋隨機結果」，討論後加入**排除最近吃過**，解決一直抽到同一個的問題
2. 發現如果先決定結果、轉盤卻停在別格會很怪，所以改成「先選目標再反推停止角度」，並用程式自動測試 200 次，確認指針位置與結果 100% 一致
3. 原本一抽到就記錄，後來改成彈窗讓使用者選「就決定是你了」或「再轉一次」，不想吃的不會被記到紀錄裡
4. 加入範本清單，第一次打開不用自己慢慢輸入
5. 加入音效、深色模式、手機版排版
